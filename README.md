# DSA

A collection of Data Structures & Algorithms problems, solved and organized by topic. Solutions are written in C++ and Python as part of daily practice.

## Structure

Each folder groups solutions by topic. Files are generally named after their source (e.g. `LC_35.py` for LeetCode problem 35).

| Topic | Description |
|---|---|
| `BACKTRACKING` | Backtracking problems |
| `BINARY_SEARCH` | Binary search on arrays and search spaces |
| `CYCLIC_SORT` | Cyclic sort pattern |
| `DISJOINT_SET_UNION` | Union-Find / DSU |
| `DYNAMIC_PROGRAMMING` | DP problems |
| `GRAPHS` | Graph algorithms |
| `GREEDY` | Greedy algorithms |
| `HEAP` | Heap / priority queue problems |
| `INTERVALS` | Interval scheduling and merging |
| `MONOTONIC_STACK` | Monotonic stack pattern |
| `OOPS` | Object-oriented design practice |
| `SLIDING_WINDOW` | Sliding window pattern |
| `SUBSET` | Subsets / combinations |
| `TREE` | Tree traversal and problems |
| `TRIES` | Trie data structure |
| `TWO_POINTERS` | Two pointer pattern |

## Running

**Python**
```bash
python <path-to-file>.py
```

**C++**
```bash
g++ <path-to-file>.cpp -o solution
./solution
```

## Progress

New topics and solutions are added regularly as part of ongoing DSA practice.
